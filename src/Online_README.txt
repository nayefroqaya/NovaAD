NovaADLS Standard / Online adapter

Copy all six Online_*.py files into the existing NovaADLS src directory.
Do not overwrite original files. Run from src:
python Online_main.py --dataset_name SP_150MB_ratio --data_root ../../LWADLS/datasets --device auto --fp-cost 1 --fn-cost 1 --delay-cost 1

Dependencies: existing NovaADLS environment, numpy, pandas, scipy, scikit-learn (sample_weight support), xgboost, colorama, torch, transformers, sentence-transformers. Pretrained sentiment and BERT models must be cached or downloadable. XGBoost CUDA requires a compatible XGBoost build; use --device cpu if unavailable. --mode M uses original stacking; --mode S uses original single XGBoost.

Both variants train once on complete sequences; original OCSVM (gamma=.5, nu=.045) and pseudo-labeling and classifier hyperparameter search retained. Training labels from unlabeled portion used only for diagnostics. Normal seed selection is reproducible with --seed and excludes mixed/anomalous/UNKNOWN blocks. Original splits and IDs preserved, sorted by timestamp with stable ties. Feature extraction uses same feature families and pretrained models, but TF-IDF, LDA, embedding scaling/PCA and sentiment encoding fit on training only; weighted covariance PCA is an exact-moment implementation, not bitwise identical to original PCA solver. LDA transform uses training template counts (unseen templates weight 1). No old combined feature cache is loaded. Feature extraction is precomputed using frozen per-event transforms; not a live latency measurement. SUM aggregation retained; online scores computed using incremental running sum and frozen training sequence scaler. No future events used in alert score; sequence length only used for metrics and Standard completion. Standard threshold uses validation F2; Online threshold and consecutive persistence selected on validation F2, ties favor fewer FP then shorter persistence and higher threshold. Class metrics calculated independently. Costs default to uploaded NovaADLS 10/20/5; use 1/1/1 explicitly to compare earlier DeepLog unit costs if appropriate. Output: novaadls_online_runs/DATASET/comparison.csv and policies.json.

Validation: syntax and synthetic aggregation/alert/metric tests; actual PKLs and pretrained-model / XGBoost end-to-end training not available here. No checkpoint reuse in this release because feature transformations are refitted to prevent leakage. Large datasets can still require substantial RAM for event-level features. Only load trusted pickle files.
